Income Tax Return

不動産所得の確定申告と記帳

賃貸住宅の家賃収入は、所得税では不動産所得として、毎年1月から12月の分を翌年の2月16日から3月15日の間（例年）に申告します。青色申告特別控除の額と、事業的規模かどうかで取扱いが変わるため、記帳の方法と申告の形式を年の初めに決めておくことが、申告の手間と税額の両方に影響します。制度の説明は2026年9月時点のものです。

監修：三上浩平（公認会計士・税理士）／最終更新 2026年9月29日

Calculation

不動産所得の計算と収入計上の時期

不動産所得は、家賃・共益費・礼金・更新料・駐車場収入などの総収入金額から、その収入を得るために必要な経費を差し引いて計算します。国税庁は、必要経費の代表例として固定資産税、損害保険料、減価償却費、修繕費を挙げています。借入金の利子も経費になりますが、元本の返済は経費になりません。

収入を計上する時期の原則

収入の種類計上する時期
家賃（支払日が契約で決まっている）その支払日。入金が遅れても、支払日の属する年の収入になります
家賃（支払日が決まっていない）実際に受け取った日。請求のときに支払う定めがあれば請求日
礼金・権利金（引渡しが必要なもの）物件を引き渡した日
敷金・保証金返還が不要と確定した日に、初めて収入になります
裁判で争っている家賃判決や和解が成立した日

国税庁 タックスアンサー No.1376 による。年末に前受けした翌年分の家賃の扱いは、契約書の支払日の定めで決まります。

決算では、通帳の入出金をそのまま集計するだけでは足りません。次の点を年ごとに確認します。

  1. 管理会社からの送金明細は、家賃収入から管理手数料や修繕費が差し引かれた後の金額です。収入は差引前の総額で計上し、差し引かれたものは経費として別に計上します
  2. 借入の返済額のうち、経費になるのは利子だけです。返済予定表で利子と元本を分けます
  3. 修繕費と資本的支出の区分、建物の減価償却費は年ごとに固定資産台帳で管理します（詳しくは減価償却と修繕のページ）
  4. 自宅と兼用している費用（通信費、車両など）は、事業として使った割合で按分します

Blue return

青色申告特別控除と申告の形式

青色申告をするには、その年の3月15日までに青色申告承認申請書を税務署に提出します。その年の1月16日以降に業務を開始した場合は、業務開始の日から2か月以内です。承認を受けると、次の特別控除が使えます。

青色申告特別控除の区分

控除額主な要件
10万円55万円・65万円の要件を満たさない青色申告者
55万円不動産所得または事業所得があり、複式簿記で記帳し、貸借対照表と損益計算書を申告書に添付して、期限内に申告する
65万円55万円の要件に加えて、e-Taxで期限内に申告する、または仕訳帳・総勘定元帳を電子帳簿保存する（電子帳簿保存の場合は、優良な電子帳簿の要件を満たし、届出書を提出します）

国税庁 タックスアンサー No.2072 による。不動産所得では、事業的規模に当たらない場合の控除は最高10万円です（No.1373）。控除額は、その年の所得の金額が上限です。

令和8年度税制改正により、令和9年分（2027年分）以後の所得税では、青色申告特別控除が次のとおり変わります。(1) 65万円控除の要件に、確定申告書・貸借対照表・損益計算書等をe-Taxで期限内に提出することが加わります（電子帳簿保存だけでは65万円になりません）。(2) 上の要件に加えて、仕訳帳・総勘定元帳の電子帳簿保存も行う場合は、控除額が75万円に引き上げられます。(3) 10万円控除は、不動産所得または事業所得を生ずべき事業を営み、前々年分の収入金額が1,000万円を超える方は対象から除かれます。令和8年分（2027年3月に申告）は、上の表のとおりです。

白色申告と青色申告の10万円控除、55万円控除、65万円控除の差額は、所得税率と住民税率の合計をかけた額が税額の差になります。課税所得が900万円を超える部分の所得税率は33%、住民税は10%のため、65万円の控除がある場合と10万円の場合とでは、55万円の差が課税所得から外れることになります。年に一度、複式簿記の記帳と貸借対照表を整えておくと、融資を受ける際の決算書としても使えます。

Business scale

事業的規模の判定（5棟10室）

国税庁は、貸家などの貸付けが事業として行われているかどうかについて、アパート等は貸与できる独立した室数がおおむね10室以上、独立家屋はおおむね5棟以上を目安としています。この基準を満たすと「事業的規模」として扱われ、次の取扱いが変わります。

事業的規模かどうかによる違い

項目事業的規模それ以外
青色申告特別控除最高65万円最高10万円
青色事業専従者給与（家族への給与）経費にできる経費にできない
貸倒損失その年の必要経費に全額算入対応する不動産所得の額が限度
資産損失（建物の取壊しなど）全額を必要経費に算入その年の不動産所得が限度

国税庁 タックスアンサー No.1373 による。5棟10室に届かない場合も、貸付けの規模や管理の実態から事業として認められることがあるため、形式だけで判断せず、物件の状況を確認します。

判定は、棟数と室数を数えるだけでは済みません。数える単位で迷う点は次のとおりです。

  • アパート1棟は室数で数え、独立した戸建は1棟として数えるため、戸建とアパートが混在している場合は両方の基準を確認します
  • 駐車場の貸付けを併せて行っている場合は、台数を室数や棟数に換算する基準がタックスアンサーに示されていないため、貸付けの規模と実態から判断します
  • 共有名義の物件は名義人ごとに申告するため、所得の配分と、各人の規模の判定を別々に確認します
  • 法人が持つ物件は、個人の棟数には数えません。個人と資産管理会社を併用している方は、個人の棟数を別に管理します

Loss

赤字のときの損益通算と土地の借入利子

不動産所得が赤字になった場合、原則として給与所得など他の所得と通算できます。ただし、土地を取得するための借入金の利子は、その部分を必要経費として算入しても、他の所得との損益通算はできません（租税特別措置法41条の4）。別荘のように主に趣味や保養のために持つ不動産の貸付けによる損失も、通算の対象外です。

  • 土地と建物を一括で購入し、借入金で両方を賄った場合は、借入金のうち建物の価額に達するまでを先に建物の取得に充てたものとして、土地に対応する利子を計算します
  • 赤字が出ない年は、この制限は働きません。減価償却費が大きい築浅の物件を取得した年や、修繕費が重なった年に確認が必要になります
  • 借換えをした場合、借入の使い道の判定が変わる場合があるため、借換え前後の契約書を保存してください

FAQ

よくある質問

白色申告のまま何年も申告しています。今から青色に変えられますか。
変えられます。青色申告承認申請書を、適用を受けたい年の3月15日までに提出します。たとえば2027年分から適用するなら、2027年3月15日までです。貸借対照表を作るには開始時の資産と借入の残高が必要なため、前年末の状況を整理するところから始めます。
管理会社に任せていて、帳簿は付けていません。
管理会社の送金明細と借入の返済予定表があれば、記帳は可能です。ただし、管理会社が差し引いた手数料や修繕費の内訳が明細に載っていない場合は、追加の資料をお願いします。
夫婦で物件を共有しています。申告はどうなりますか。
共有物件の所得は、持分に応じて各人に配分して、それぞれが申告します。名義人ごとに収入と経費の按分を確認します。
5棟10室に届いたら、届出は要りますか。
事業的規模の届出という手続きはありません。青色申告の承認を受けたうえで、決算書で申告するときに事業的規模として扱います。
