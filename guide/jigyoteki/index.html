Business Scale

事業的規模（5棟10室）

不動産の貸付けが事業的規模かどうかで、資産損失の扱い、貸倒損失の計上、事業専従者給与、青色申告特別控除の上限が変わります。「5棟10室」という呼び方は広く使われますが、国税庁の説明では棟数と室数は別々の目安です。その読み方と判定の例を整理します。

Criteria

基準の内容

国税庁は、貸付けが事業として行われているかどうかを、社会通念上事業と称するに至る程度の規模で行われているかで、実質的に判断するとしています。そのうえで、建物の貸付けについては、次のいずれかに当たれば、原則として事業として扱われるとしています。

建物の貸付けの形式的な目安

貸付けの種類目安
貸間・アパート等貸与できる独立した室数が、おおむね10室以上
独立家屋おおむね5棟以上

「おおむね」の目安であり、この数を下回れば直ちに事業ではないとされるわけではありません。貸付けの規模と実態を総合して判断されます。

How to Read

「5棟10室」の読み方

  • 「5棟」は独立家屋（戸建て）の目安で、「10室」はアパートや貸間の目安です。二つを合算して数える基準ではありません。
  • アパートは、建物の棟数ではなく、貸与できる独立した室数で数えます。1棟に10室あれば、それだけで目安に達します。
  • 戸建てとアパートの両方を持つ場合は、棟数と室数を機械的に足さず、貸付けの規模と実態から判断します。

基準への当てはめを架空の例で示します。

基準への当てはめ（架空の例）

保有の例（架空）貸間・アパートの室数独立家屋の棟数目安との関係
アパート1棟（8室）8室0棟室数の目安（10室）に届かない
アパート2棟（各6室）12室0棟室数の目安（10室）を上回る
戸建て4棟0室4棟棟数の目安（5棟）に届かない
戸建て6棟0室6棟棟数の目安（5棟）を上回る
戸建て3棟とアパート1棟（6室）6室3棟どちらの目安にも届かない。実態で判断

What Changes

事業的規模になると変わること

事業的規模かどうかによる取扱いの違い

項目事業的規模事業的規模でない場合
資産損失全額を必要経費に算入その年の不動産所得の金額を限度
貸倒損失回収不能になった年分に計上収入に計上した年分にさかのぼって所得を修正
事業専従者給与適用あり適用なし
青色申告特別控除最高65万円最高10万円

資産損失は、取り壊しや災害などで建物に生じた損失で、事業的規模なら全額を必要経費にできます。そうでない場合は、その年の不動産所得の金額が限度です。

貸倒損失は、家賃の回収ができなくなった場合の損失です。事業的規模なら、回収不能になった年の必要経費にします。そうでない場合は、収入に計上した年分にさかのぼって所得を修正します。過去の年分の申告書を見直すため、手続きの負担が増えます。

Blue Return

青色申告特別控除との関係

青色申告特別控除は、10万円、55万円、65万円の3段階です。55万円控除は、不動産所得または事業所得を生ずべき事業を営んでいること、複式簿記で記帳すること、貸借対照表と損益計算書などを申告書に添付すること、現金主義による所得計算の特例を選択していないことが要件です。65万円控除は、これに加えて、仕訳帳と総勘定元帳の電子帳簿保存を行うか、申告書をe-Taxで送信することが要件です。

事業的規模に至らない場合の控除は、最高10万円です。控除額の差は最大55万円で、所得税と住民税の負担に影響します。ただし、55万円以上の控除を受けるには、複式簿記による記帳と決算書の作成が必要です。

青色申告をするには、青色申告承認申請書をその年の3月15日までに提出します。新たに業務を始めた場合は、業務を始めた日から2か月以内です。

令和8年度税制改正により、令和9年分（2027年分）以後の所得税では、青色申告特別控除が次のとおり変わります。(1) 65万円控除の要件に、確定申告書・貸借対照表・損益計算書等をe-Taxで期限内に提出することが加わります（電子帳簿保存だけでは65万円になりません）。(2) 上の要件に加えて、仕訳帳・総勘定元帳の電子帳簿保存も行う場合は、控除額が75万円に引き上げられます。(3) 10万円控除は、不動産所得または事業所得を生ずべき事業を営み、前々年分の収入金額が1,000万円を超える方は対象から除かれます。令和8年分（2027年3月に申告）は、上の表のとおりです。

Practice

当事務所が判定で確認すること

  1. 物件ごとの棟数、室数、独立した各部分の数
  2. 各物件の貸付けの開始日、賃貸の状況
  3. 所有者（個人か法人か）と、共有の有無
  4. 貸倒れになった家賃と、取り壊しや災害による損失の有無
  5. 記帳の方法（複式簿記かどうか）と、e-Taxの利用の有無

事業的規模かどうかは、毎年の申告でその年の貸付けの状況に応じて判断します。物件を売却して棟数や室数が減った年や空室が続いた年は、前年と同じ取扱いになるとは限りません。

目安に届く時点は、取得前に見通せます。取得前の個別相談（90分22,000円・税込）で、取得後の申告と記帳の見通しをお伝えします。
